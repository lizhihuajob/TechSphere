## 项目简介

TechSphere 2026 是一场汇聚全球科技精英的年度盛会官方网站。本网站采用纯前端技术栈开发，提供完整的峰会信息展示、演讲者简介、议程时间表和响应式活动地图等功能。

## 技术栈

- **HTML5**: 语义化页面结构
- **CSS3**: 响应式设计、动画效果、Flexbox/Grid布局
- **原生 JavaScript**: 无框架依赖，轻量级交互
- **Nginx**: Web服务器（Docker部署）
- **Docker**: 容器化部署
- **Docker Compose**: 一键部署

## 部署方式

### 方式一：Docker Compose 一键启动（推荐）

1. 确保已安装 Docker 和 Docker Compose

2. 在项目根目录执行：
```bash
docker-compose up -d --build
```

3. 访问网站：
```
http://localhost:8080
```

4. 停止服务：
```bash
docker-compose down
```

### 方式二：Docker 手动构建和运行

1. 构建镜像：
```bash
docker build -t techsphere-website .
```

2. 运行容器：
```bash
docker run -d -p 8080:80 --name techsphere techsphere-website
```

3. 访问网站：
```
http://localhost:8080
```

### 方式三：本地直接访问（开发模式）

直接用浏览器打开 `index.html` 文件即可预览，无需服务器。

## 开发说明

### 修改内容
- **页面内容**: 编辑 `index.html`
- **样式设计**: 编辑 `css/style.css`
- **交互逻辑**: 编辑 `js/main.js`
- **演讲者数据**: 修改 `js/main.js` 中的 `speakersData` 数组
- **议程数据**: 修改 `js/main.js` 中的 `agendaData` 对象

### CSS 变量说明
```css
:root {
    --primary-color: #6366f1;    /* 主色调 - 紫色 */
    --secondary-color: #10b981;  /* 辅助色 - 绿色 */
```
